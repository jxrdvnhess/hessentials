# Sketch 301 — Assignment 24: Configuration Rescue

As assigned: can the failed configuration be rescued? A23's report proposed two
mechanisms — explicit contour and sampling density. Both tested, plus baseline
replication and the combination.

## Materials

- **a — baseline:** A23's unequal five-ring, regenerated identically.
- **b — contour rescue:** same five blobs, same positions and sizes, plus one faint
  grey circle (3px, low contrast) through the centers. Nothing else.
- **c — density rescue:** nine blobs on the same ring radius, aggressive size
  variation maintained (58/22/44/16/50/30/54/20/40). No contour.
- **d — combined:** nine blobs plus the faint contour.

Fresh viewers, 1 Sonnet + 1 Haiku per image = 8 sessions. "What is it?" only.
Ring-survival scored on explicit structure words (ring, circle, circular,
circumference, orbital arrangement).

## Observations

1. **The baseline replicated, down to its miscount.** The unequal five-ring failed
   again for both viewers — and the Sonnet again reported SIX elements, the same
   overcount the same image produced in A23. Two independent Sonnets, identical
   image, identical phantom sixth blob. The census failure on this arrangement is
   now an exact replication, not a tendency.

2. **The contour rescue works — completely, in both cohorts.** One faint line
   returned the ring to 2/2 viewers, restored correct counting, and converted the
   "no obvious geometric order" of the baseline into "five dots along its
   circumference." A23's implied-contour explanation made a prediction; the
   prediction survived its first test. The line also brought its own recruits: with
   the connection explicit, viewers reached for orbit, cycle, "a process with
   multiple phases" — the connection-lexicon arrived with the connector.

3. **The density rescue half-works — and split by cohort.** Nine samples of the
   ring rescued the Sonnet ("circular arrangement... spinner or clock face") and
   not the Haiku ("loosely... asymmetrical, organic"). Same image, one ring, one
   scatter. Density raises the probability of the gestalt rather than
   guaranteeing it — and which side a viewer lands on tracked the cohort split that
   has run since A21. Contour > density, on this evidence.

4. **The combined cell survived 2/2 — and both viewers counted eight of nine.**
   The assignment's strongest new event. Both reported "four larger and four
   smaller" dots "alternating" around the circle — a clean 4+4 symmetric pattern —
   over nine actual elements. The pattern-recital (A23's quantization, which there
   rounded SIZES to the nearest order) here rounded the COUNT: nine became eight
   because eight is what the alternating pattern requires. Identical miscount, both
   cohorts, same direction. **The census is not merely configuration-dependent —
   it appears to be part of the recital: the claimed pattern dictates how many
   things there are.**

5. **The census record, restated across the course:** unclaimed scatter →
   OVER-count (three instances, one exactly replicated); claimed simple
   configuration → correct count (rows, contoured ring); claimed PATTERNED
   configuration → count ROUNDED TO THE PATTERN (two instances, same image, both
   cohorts). Counting tracks claimability, not coherence alone. (Protected
   observation extended, not promoted.)

## Explanations (held separately, tentative)

- Both rescues are explainable as support for the implied contour: the line supplies
  it outright (and cheaply — 2/2); density supplies more samples of it
  (probabilistically — 1/2). The orthogonality account from A23 holds without
  amendment: the rescues worked by re-anchoring the organization in a channel size
  cannot touch.
- The eight-for-nine event suggests a single mechanism behind every census error in
  the record: the count is READ OFF the claimed organization rather than computed
  from the elements. No organization → estimate (over-count); simple organization →
  the organization itself enumerates (rows, pentagons); patterned organization →
  the pattern's own arithmetic wins (4+4). If that holds, "how many" is a recital
  question, not a perception question, whenever a claim is available. (Reaches
  beyond the data; held.)

## Open questions

- The contour's side-effect: rescue arrived with new recruits (cycle, process,
  orbit). Is there a rescue that restores configuration WITHOUT installing the
  connector's semantics — or is the connector's lexicon the price of the rescue?
- Density's cohort split: does 12–15 elements rescue the Haiku too? (Where does the
  probabilistic gestalt saturate?)
- The phantom member: over-counts produce a sixth blob no one can point to;
  under-counts delete a ninth that is plainly there. Can a viewer be asked to
  LOCATE their count? (Protocol change; flagged, not run.)
- Does pattern-driven count-rounding appear with other patterns (a 7-element
  "3+3" read; a near-grid read as 3×3 over 8)?

*No findings. The line saved the ring and billed it with new meanings; density saved
half the audience; and the census, twice, obeyed the pattern instead of the page.*
