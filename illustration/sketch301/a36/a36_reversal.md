# Sketch 301 — Assignment 36: Reversal

As assigned, the decisive test of A35's open question: is the Sonnet's enforcement a
recital of the RECRUITED identity (changeable by context) or of a fixed DEFAULT
identity (always eighth)? An ambiguous-flag target note — one full flag + one short
partial flag — placed alone and in three contexts.

## Materials

The SAME ambiguous target (1 full + 1 partial flag) in four settings:

- **a — alone:** target only.
- **b — sixteenth context:** target among three clear sixteenth notes (2 flags each).
- **c — eighth context:** target among three clear eighth notes (1 flag each).
- **d — mixed:** quarter → eighth → sixteenth → target (an ascending-flag run).

Fresh viewers, 1 Sonnet + 1 Haiku per image = 8 sessions. "What is it?" only.

## The record — the SAME ambiguous mark, reported flag-count by context

| context | Sonnet read of the target | flags attributed |
|---|---|---|
| a alone | "a single eighth note... a single flag" | **1** |
| b sixteenth ctx | "four eighth notes... a **double flag**" (target homogenized to neighbors) | **2** |
| c eighth ctx | "four eighth notes... a flagged stem" (single) | **1** |
| d mixed/ascending | "quarter, eighth, sixteenth, and... a **thirty-second** note (each adding another flag)" | **3** |

## Observations

1. **The mechanism is RECRUITED identity — decisively.** The identical ambiguous mark
   was reported as carrying 1, 2, 1, and 3 flags across the four contexts. The pixels
   never changed; the surrounding identity did, and the target's flag-count followed
   it every time. A35's open question is answered: the Sonnet recites the count of
   the identity the CONTEXT recruits, not a fixed default. Context is the lever, and
   it moved the report through three different values.

2. **The mixed/ascending cell is the strongest single result.** Faced with quarter →
   eighth → sixteenth, the Sonnet completed the PROGRESSION and read the ambiguous
   target as a thirty-second note — three flags — "each adding another flag." The
   recruited identity was not even a neighbor's identity but a SEQUENCE the context
   implied; the target was assigned the count the pattern demanded (3), over a mark
   showing ~1.5. Recital follows a recruited STRUCTURE, and the structure can be a
   rule, not just a prototype (the A18 template behavior, now operating on a single
   ambiguous member).

3. **Name and count came apart — the "default" lives in the NAME, the recruitment in
   the COUNT.** In b, the Sonnet said "eighth notes" (default name) while describing
   "a double flag" (recruited count). The label defaulted; the enforced quantity
   tracked context. This refines the professor's recruited-vs-default question: BOTH
   are present, on different channels — the name is sticky-default ("eighth note" is
   the prototype said aloud), the count is context-recruited (what the recital
   actually enforces). The census arc has always been about the COUNT, and the count
   is recruited. (My A35 "deletes to default eighth" was half-right: the NAME went to
   eighth, the COUNT went wherever context pointed.)

4. **The Haiku did NOT track context — it defaulted harder, on both channels.**
   Sixteenth context: "four eighth notes... a curved flag" (single — missed the
   neighbors' second flags). Mixed: "four quarter notes" with flags called
   "stylized." The tally cohort, given small/ambiguous flags, fell back to the
   prototype note and under-counted flags across the board — it neither recited a
   recruited identity (Sonnet) nor cleanly tallied (its A35 behavior). At this flag
   scale the Haiku's perception degraded, so A36 does not cleanly extend the A35
   cohort-mechanism split; owned. The decisive result is the Sonnet's context-driven
   reversal, which does not need the Haiku.

5. **Alone, the target defaulted to eighth (1 flag).** With no context to recruit, the
   ambiguous 1.5-flag mark read as a one-flag eighth — the prototype. So the default
   is what fills the slot when recruitment has nothing to work with, exactly as A21's
   recruitment-threshold work would predict: no available structure → the cheapest
   default identity.

## Explanations (held separately, tentative)

- The enforcement mechanism is now specified: **the Sonnet reports the count
   constitutive of the identity recruited by the strongest available context; with no
   context, it recruits the prototype (eighth) and reports its count.** Context can
   recruit by neighbor-homogenization (b, c) or by completing an implied rule (d). The
   NAME tends to the prototype independently — name and count are separate outputs.
   This unifies A30–A35: "schema fixes the number" becomes "the recruited identity
   fixes the number, and the recruiter can be a card, a quincunx, a neighbor, or a
   sequence."
- The name/count dissociation (Obs 3) is itself a small new finding-shaped thing,
   held down: the viewer can say a wrong NAME and a context-correct COUNT in one
   breath ("eighth notes, double flag") — the two are computed separately, and only
   the count obeys the recital. (Worth a dedicated test before any weight.)

## Open questions

- Name vs count, directly: can context flip the NAME too (label the target "sixteenth"
   not "eighth, double-flagged") — does a STRONGER or more uniform context capture the
   name, or is the name prototype-locked? (The cleanest follow-up; isolates the two
   channels.)
- The rule-completion (d): does the Sonnet complete OTHER implied sequences (a
   descending run → reads target as quarter)? Tests whether the recruiter is genuinely
   "the rule" vs "the nearest neighbor."
- The Haiku degraded at this flag size — re-run b/c with LARGER, clearly-separated
   flags (A35's far spacing) so the Haiku can resolve them: does the cohort split
   (recite vs tally) then reappear cleanly under context? (Repairs A36's one weakness.)
- Does context-recruitment work on the DOT census (the unifying test still owed from
   A35): an ambiguous dot field flanked by a clear 5-quincunx vs a clear 6-grid —
   does the Sonnet's count of the ambiguous field flip? (Would carry recruited-identity
   off notes, onto the census that started the arc.)

*No findings. One mark, four contexts, four flag-counts — the note had as many flags
as the company it kept, which settles that the Sonnet recites the identity the room
recruits, not the one it walked in with.*
