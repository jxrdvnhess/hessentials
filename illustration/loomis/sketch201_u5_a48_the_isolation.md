# Sketch 201 · Unit 5 · A48 — The Isolation

A47 established the hierarchy and left six explanations unseparated. A48 isolates three, one pair at
a time, everything else held fixed — same calf, same gap (~0.09 units). Page:

## Pair 1 — Routes (muzzle off, no route vs muzzle off, tethered)

A jaw line was added so the displaced muzzle keeps one route to the head; the displacement is
identical. What the page shows: the tethered version does not read as broken at all. The held muzzle
reads as articulation — a lifted, open muzzle, almost a bellow. One remaining route preserved unity
completely, and the gap re-read as expression. The unheld version stays an animal and a dot.

*Caveat owned:* the tether is an added eleventh mark, so this pair is not pure — the repair could
owe something to the new information, not only the new route.

## Pair 2 — Objecthood (same detachment, filled vs outline)

The filled fragment reads as a solid second object — a stone beside the head. The outline fragment
reads as something unexplained — a ring, a bubble. Both panels stay broken. On this page, fill
changed *what the fragment becomes*, not *whether the break costs*. A secondary variable.

## Pair 3 — Location (equal filled single-route piece: muzzle at the head vs tuft at the rump)

The tuft-off panel: the cow remains whole and a pebble sits in the field behind it. The muzzle-off
panel: the cow itself is incomplete — the head reads truncated — and a rival object floats beside
it. Same mass, same gap, same single route. What differs on this page is not where the viewer looks
but what the remainder loses: the head needed its muzzle; the rump never needed the tuft.

*Caveat owned:* the tuft is a luxury added to be broken — its baseline is contrived.

## What the page suggests (observation, not theory)

On this page a break carries two separable debts: what the body loses, and what the fragment
becomes. The expensive break (muzzle, unheld) pays both. The tuft break pays only the second. The
tethered break pays neither — and narrative absorption reappears here as a property of the route:
a held piece's displacement becomes expression; a free piece's becomes a second thing.

Attention never had to be invoked to read this page. That does not disprove it; it means the
location effect that A46 attributed to attention is, on these panels, fully accounted for by need —
which is A44's old finding arriving from the other side: the muzzle was answering a question the
drawing asks; the tuft wasn't. Held to these six panels and this calf.
